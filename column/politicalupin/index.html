ドラマ『ポリティカルパン』に関連する実在事件

フジテレビ系ドラマ『ポリティカルパン』（2026年10月〜、脚本・野木亜紀子）の各話に登場する「政治とカネ」の題材と、それに対応する実在の事件を、話数ごとに解説します。

コンセプト

『ポリティカルパン』は、架空の国「ニッポニア」を舞台に、怪盗・如月弥生（石原さとみ）が使途不透明の「ポリティカル・マネー」を盗もうとする政治エンターテインメント。作中は架空の世界ですが、官房機密費、選挙前の現金配布、ネット世論工作、政治資金パーティー、政党交付金など、現実の日本政治で実際に問題になった題材が下敷きになっています。

「本当に現実の日本で起こったこと？」と気になっている方に向けて、本作のモチーフになったと思われる実在の事件を列挙しました。なお、この対応づけは制作側が公表したものではなく、当サイトの解釈です。

各話と実在の事件

第1話「箱の中の娘」

テレビで元政治家らしき人物が、官房機密費の実態を暴露します。官房長官室の金庫には財務省から札束が補充され続け、領収書も使途の公開も要らないまま、政党のためにばらまかれているというのです。

弥生はこれを狙うと決め、政界に潜り込むために政治家一族の娘・雅を衆院選に立候補させます。

  • 官房機密費：テレビで暴露された、領収書も使途の公開も要らない金です。劇中では、与党幹部が選挙資金を「あちらの金庫から」出すよう官房長官に頼む場面もあります。
    • 菅義偉は官房長官在任中に機密費86億円超を使用し、その約9割は領収書不要の「政策推進費」として自身に支出したものでした。
    • 松野博一（自民）は裏金問題で辞任する直前の14日間に機密費4660万円を支出しました。
    • 元官房長官が、機密費を国政選挙候補者への陣中見舞いに使ったと証言しています。
    • 野中広務（自民）は、官房長官時代に機密費から政治評論家らに盆暮れ500万円ずつ届けていたと、テレビ番組などで証言しました。
    • 市民団体「政治資金オンブズマン」の訴訟で、最高裁は2018年に機密費の文書の一部開示を初めて命じました。ただし、支払先や使途は今も明らかになっていません。
  • 国保逃れ：ニュース番組で、与党・国自党の地方議員360名が一般社団法人の名目上の理事になり、国民健康保険料を大幅に安くしていた問題が報じられます。副総裁は「個人の問題」とかわし、幹事長は数人の処分で幕引きかと問われても「調査中」を繰り返します。
    • 維新の議員らが同じ手口で国保逃れをしていたことが、大阪府議会で指摘されました。
    • 佐竹璃保（維新・大阪市議）らが、一般社団法人の理事に就任していた疑いが浮上しました。
    • 維新の党内調査では社会保険加入者が364人と判明し、党は6人の除名で調査を終えました。
  • ウナギ：夏目は、絶滅が危惧されているウナギのかば焼きが議員の食事に毎日出てくることに疑問を投げかけます。
    • 小泉進次郎農水相は、ウナギは絶滅危惧ではないと発言しました。
    • 水産庁は、ワシントン条約でのウナギの国際取引規制の強化に反対しました。
    • 水産庁は、シラスウナギの無報告流通を長年放置してきました。
  • 任期途中の衆院解散：解散で万歳する議員たちを見て、夏目が「任期が残っているのに」「総選挙の費用900億を子育て支援に回せるだろ」と声を荒げます。
    • 高市早苗は就任3カ月ほどで、自身への信任を問うとして衆院解散を表明しました。2月8日投開票という真冬の総選挙は36年ぶりで、選挙費用は予算ベースで850億円超と過去10年で最高でした。

第2話「17区」

選挙戦が始まります。公認を得た兄・颯の陣営は、党からの2000万円と大勢の党員・ボランティアに支えられています。雅の陣営は、借金をしてかき集めた300万円で戦います。

公示前には颯陣営の秘書が県連を回り、「季節のご挨拶」として現金を配っていました。夏目はこれを、県議や市議に地元の票をまとめてもらう「手間賃」だと説明します。選挙期間前で「票を入れてくれ」と言わなければ違反にならない、という暗黙の了解です。後から領収書を出して収支報告書に寄付と書けば合法になり、報告書が公開されるのは選挙の1年以上先だとも話します。

投票日直前には、現金の代わりに宝くじが配られていたことが報じられ、買収疑惑として騒ぎになります。

  • 党から公認候補への資金：公認を得た颯の陣営には、党から2000万円が支給されます。
    • 自民党は2024年衆院選で、裏金事件で非公認とした候補の党支部にも公認候補と同額の2000万円を振り込んでいました。森山裕幹事長は「候補者に支給したものではない」と釈明しましたが、支部の代表は非公認候補本人でした。
  • 地方議員への現金配布：颯陣営の秘書が公示前に県連を回り、「季節のご挨拶」として県議や市議に現金を配ります。夏目は、地元の票をまとめてもらう「手間賃」だと説明します。
    • 河井克行（自民）は2019年参院選で地元の地方議員ら100人に計約2870万円を配り、実刑判決を受けました。
    • 柿沢未途（自民）は江東区長選で区議らに現金を渡し、「陣中見舞い」だと説明しましたが、買収で有罪判決を受けました。
  • 現金以外の物を配る買収：投票日直前、現金の代わりに宝くじが配られていたことが報じられ、買収疑惑として騒ぎになります。
    • 武部新（自民）の後援会幹部は、運動員に報酬として商品券を渡した買収容疑で逮捕されました。
  • 報告書の後付け：夏目は、後から領収書を出して収支報告書に寄付と書けば合法になり、報告書が公開されるのは選挙の1年以上先だと話します。
    • 岸田文雄は、選挙運動費用収支報告書に宛名や但し書きのない領収書94枚を添付していました。
    • 武部新（自民）は、無償の運動員と記載したカメラマンに約86万円を支払っていたと報じられ、その後に報告書を訂正しました。

第3話「怒り」

当選後、雅は父から与党・国自党への入党を勧められますが、断ります。

弥生たちは、選挙中に雅を誹謗中傷していた匿名アカウントについて発信者情報開示請求を行います。投稿元は、平日の勤務時間に投稿していた会社でした。社長は党の金庫番を50年以上務める党職員の親戚で、会社は与党の都連から総額2500万円を受け取っていました。

同じ頃、外国人が生活保護を食い物にしているという動画が、事実かどうかに関係なく再生数稼ぎのために作られていることも描かれます。

  • ネット工作会社：雅を中傷していたアカウントの投稿元「ポンズネクスト」は、党の金庫番を50年以上務める党職員の親戚が社長の会社で、与党の都連から総額2500万円を受け取っていました。
    • 匿名アカウント「Dappi」の投稿は、ウェブ制作会社「ワンズクエスト」の業務だったと裁判で認定されました。劇中の「ポンズネクスト」は、この社名とソースネクストをもじったものと考えられます。
    • ワンズクエストは自民党東京都連から支払いを受けており、社長は自民党本部の事務方トップ・元宿仁事務総長の親族と報じられています。元宿氏は議員ではなく、1970年代から党本部で経理を担ってきた職員とされます。
    • 岸田文雄は、自民党との資金の流れの調査を拒否しました。
    • 松野博一（自民）は、機密費を世論操作に使ってよいかという質問に定型答弁を繰り返しました。
    • 山本有二（自民）は、Dappi発信元会社の社長への謝礼を収支報告書に記載していませんでした。
    • 石破茂が打ち出した「公開方法工夫支出」では、Dappi運営会社のような支出先が非公開になり得ることを本人が認めました。
  • 陣営による匿名の中傷動画：劇中の工作会社は、一般人を装って野党やライバルの悪評をばらまいていました。
    • 2025年の自民党総裁選で、高市早苗陣営が小泉進次郎・林芳正を中傷するAI動画を匿名アカウントで拡散していたと週刊文春が報じました。
    • 2026年の衆院選でも、高市早苗陣営の動画で枝野幸男や岡田克也ら野党候補が標的になったと報じられています。
    • 高市早苗の秘書は陳述書で関与を否定しましたが、動画作成の依頼を示すメッセージなどの証拠と矛盾すると報じられています。
    • 声紋鑑定で同一人物と推定された後も、高市早苗は秘書と動画作成者との面識を否定し続けました。
    • 同じ総裁選で、小泉進次郎陣営も一般視聴者を装ったコメントの投稿を指示していました。
  • 外国勢力による選挙介入：官房長官は、ネット上で虚偽の情報が拡散しているのは外国勢力による世論への介入だという分析があると答弁し、AIも使った対策を講じると述べます。劇中では、与党とつながった国内の工作会社が中傷を続けている中での答弁として描かれます。
    • 平将明（自民）デジタル相は、2025年の参院選でボットが社会を分断する投稿を拡散した可能性に言及し、対策の司令塔となる部署の設置を訴えました。
    • 参院選では、参政党候補の塩入清香（さや）のインタビューをロシア国営メディア「スプートニク」が投稿し、ロシアの関与を疑う見方が広がりました。神谷宗幣（参政）は「参政党は親露派ではない」と反論しましたが、琉球新報のファクトチェックはこれを「不正確・ミスリーディング」と判定しています。
  • 選挙をめぐる虚偽情報：選挙中、雅についてのデマや中傷がネットで拡散されます。
    • 早坂敦（維新）の陣営は衆院選で、対立候補についての虚偽情報を書いたビラを配り書類送検されました。
    • 立花孝志（NHK党）は、亡くなった竹内英明元兵庫県議についての虚偽情報を発信し、名誉毀損容疑で逮捕されました。
  • 外国人をめぐる不正確な情報：外国人が生活保護を食い物にしているという動画が、受給率の数字の裏付けもないまま、再生数稼ぎのために作られます。
    • 高市早苗は総裁選の演説で、外国人観光客が奈良公園のシカを蹴ったり殴ったりしていると発言しました。
    • 高市早苗は根拠を問われても「自分なりに確認をした」と述べるだけで、奈良県庁は行為者が外国人かどうかは特定されていないと説明しました。
    • 高市早苗は、野党からのシカ発言の撤回要求を拒否しました。
    • へずまりゅうは、外国人観光客によるシカ虐待を主張する動画やAI合成が疑われる画像を投稿していました。高市早苗のシカ発言の背景とされます。
    • 高市早苗は同じ総裁選で、通訳の手配が間に合わず外国人を不起訴にせざるを得ないと「よく聞く」と発言しましたが、関係者は「そんな事案は聞いたことがない」としています。
    • 神谷宗幣（参政）は「外国人からは相続税が取れない」と事実と異なる発言をしました。
    • 玉木雄一郎（国民）は、外国人の利用が1%程度とされる制度を挙げて「外国人優遇の見直し」を主張し、排外主義を煽ると批判されました。
  • ウナギ：会食の席で、ウナギを絶滅から救うのも政治の仕事だという話になり、水産庁が補正予算で人工種苗の研究に7億円を充てたことが紹介されます。
    • 水産庁は、ワシントン条約でのウナギの国際取引規制の強化に反対しました。
    • 水産庁は、シラスウナギの無報告流通を長年放置してきました。

第4話「250円」

雅は国自党に入ります。年収を聞かれて、歳費だけで約2000万円、ほかに調査研究広報滞在費などがあると答えると、事務所に抗議の電話がかかってきます。弥生は、その大半は事務所の賃料や秘書の給料などの経費で、給料と経費を分ける法改正が必要だと答えます。

乾は、政治とお金の仕組みを説明します。30年前、企業献金の代わりとして国民1人250円の政党交付金ができたこと。それでも政党支部が受け皿になって企業献金が残ったこと。企業名を表に出さずに済むパーティー券の購入が、献金の手段として広まったこと。

裏金事件の後、派閥は解散し、現職大臣のパーティーも自粛することになっています。それでも弥生たちは、大臣が後輩議員のパーティーの案内に自分の振込口座を紛れ込ませ、資金を集めていたことを見つけます。

  • 政治資金パーティーと裏金事件：劇中では、裏金事件をきっかけに与党の派閥が解散し、パーティーに関する法律も改正されたと説明されます。派閥時代にはパーティー券の販売ノルマがあったという話も出ます。
    • 大野泰正（自民）は、安倍派のパーティー券収入を収支報告書に記載しなかったとして有罪判決を受けました。
    • 岸田文雄は裏金事件を受けて岸田派の解散を表明し、安倍派・二階派も解散しましたが、麻生派と茂木派は解散しませんでした。
    • 自民党は、裏金議員43人を衆院選で公認しました。
    • 高市早苗は、裏金事件で処分を受けた議員を入閣させました。
  • 大臣のパーティー自粛：裏金事件の後、現職大臣のパーティーは自粛することになっていますが、大臣は後輩議員のパーティーの案内に自分の振込口座を紛れ込ませて資金を集めます。
    • 井林辰憲（自民）は国交相在任中にパーティーを開き、「就任前から準備していた」として大臣規範に抵触しないと説明しました。
  • 企業・団体献金：雅は、政党交付金の原資が国民1人250円だと訴え、企業・団体献金の廃止を掲げます。野党議員の宇都宮は、野党も労働組合から団体献金を受け取っているので廃止には及び腰だと話します。
    • 小泉進次郎は、企業・団体献金の禁止に反対しました。
    • 高市早苗は、規制強化を問われ「そんなことより定数削減」と発言しました。
    • 藤田文武（維新）は与党入りを理由に、禁止法案の取り下げ意向を示しました。
    • 立憲民主党・日本維新の会・参政党・社民党・有志の会の野党5党派は、企業・団体献金禁止法案を共同提出しました。国民民主党は加わらず、禁止に賛成する党派は衆院で過半数に届きませんでした。
    • 玉木雄一郎（国民）は、野党が一致すれば禁止に賛成すると述べながら、法案には「抜け穴がある」として加わらず、自民・公明と献金を存続させる案で合意しました。
    • その国民民主党の浜口誠政調会長は、トヨタ系労組の政治団体から関連政治団体4つに分散する形で計約2億4853万円の寄付を受けていたと報じられました。
  • 政党支部を使った抜け道：乾は、議員個人への企業献金が禁止された後も、政党支部が受け皿になって企業献金が残ったと説明します。献金する企業の側が節税になるという話も出ます。
    • 井上英孝（維新）は、自分の政党支部を経由させて資金管理団体に寄付し、所得税控除を受けていました。
    • 高市早苗の事務所は、パーティー券購入を寄付として扱い、控除書類を発行していた疑いが報じられています。
    • 遠藤敬（維新）の政党支部は、公設秘書からの寄付という形で秘書給与を還流させていた疑いが報じられました。
  • 国会の中の銀行支店：雅の事務所は、国会内にある銀行の衆議院支店で政党支部の口座を作ります。
    • Dappi運営会社の社長は、国会の通行証がないと使えない衆議院支店で住宅ローンを組んでいたと報じられ、党本部とのつながりを示すものとされました。
  • 亡くなった政治家の政治団体：乾は、政党支部や政治団体の口座は何万もあり、全てを把握している者はいないと話します。亡くなった政治家の政治団体の口座が残っていて、物語の鍵になります。
    • 安倍昭恵は安倍晋三の死去後、その政治団体の代表に就任し、約2億4400万円の政治資金を非課税で引き継ぎました。議員にはなっていません。
  • 政党交付金：議員5人を集めて政党をつくれば交付金を受け取れ、使い道は党しだいだという話が出ます。
    • 維新の会は政策ブレーンに、政党交付金から5年で1.5億円超を支払っていました。
    • 石井章（維新）の政党支部は、秘書が経営する会社へ政党交付金を支払っていたと報じられました。
    • 奥下剛光（維新）の資金管理団体は、キャバクラとラウンジに計9万3500円を「交際費」として政治資金から支出していました。この団体は維新の政党支部「日本維新の会 国会議員団」から寄附を受けており、政党交付金を含む党の資金と区別なく使われる仕組みになっています。
    • 青島健太（維新）の資金管理団体も、キャバクラやガールズバーなど5店舗に計11万7400円を政治資金から支出し、収支報告書を訂正しました。
  • 調査研究広報滞在費（旧文通費）：雅は年収を聞かれて、歳費のほかに調査研究広報滞在費があると答えます。弥生は、給料と経費を分ける法改正が必要だと話します。
    • 吉村洋文は文通費の満額受給を批判しながら、自身も満額受給していました。
    • 三木けえ（維新）は旧文通費で寝具や家電を購入していました。

第5話「ニッポニア・クロニクル」

通常国会が始まり、雅は朝8時の部会から夜の会合まで、1日平均14時間働きます。一方、国自党では風祭総理の支持率が下がり、秋の総裁選に向けて副総裁の士郎が動き出します。

乾は、自分が受け継いだビルと懐中時計の持ち主だったフィクサー・片桐の話を明かします。25年前の総裁選で、片桐はハト派の井川重昭を推し、乾を対立候補・小早川一郎の秘書として送り込みました。片桐は小早川の大スキャンダルの証拠をつかんだ直後に事故で死に、総裁選は小早川が勝ちます。敗れた井川も、ゼネコンからの賄賂をリークされて議員を辞職しました。

夏目と弥生は、互いの貧しい子供時代を語り合います。夏目は、生活保護に救われて官僚になったと話し、企業優遇へと舵を切った25年間が格差社会につながったと振り返ります。
